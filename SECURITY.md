# Security

Please report security problems privately through GitHub: **Security → Report a vulnerability** on this repository. Don't open a public issue for them.

Include what you did, what happened, and which version of the plugin (`.claude-plugin/plugin.json`) and of Claude Code you used. I'll reply as soon as I can and credit you in the fix unless you'd rather not be named.

What the plugin can touch is listed in the README's "Safety" and "What the hooks do" sections; anything that reaches beyond that is in scope.
